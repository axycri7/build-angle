Automatic weekly build of [angle][] OpenGL ES implementation for 64-bit Windows (x64 and arm64) and Android (arm64-v8a with Vulkan).

Download binary build as zip archive from [latest release][] page.

To build locally run `build.cmd` batch file for Windows or `build_android.sh` for Android, make sure you have installed all necessary dependencies (see the beginning of each file).

[angle]: http://angleproject.org/
[latest release]: https://github.com/mmozeiko/build-angle/releases/latest
